# LVL-CODES

**LVL-CODES** is the main repository for various data analytics and business intelligence projects.

## Projects

### 📊 LVL-STMS (Sales Target Management System)
**Location**: `LVL-STMS/`

A comprehensive 2026 sales target management system for pet food retail & distribution with:
- Multi-model forecasting (SARIMA, Prophet, XGBoost, LightGBM, Random Forest, Ensemble)
- 16% minimum net growth targeting
- Multi-dimensional analytics (product, geography, channel)
- Inventory management & stockout prediction
- Dynamic target adjustments
- Interactive dashboards & automated reporting

**Documentation**: See `LVL-STMS/README.md`
